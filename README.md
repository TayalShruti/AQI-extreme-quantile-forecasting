# AQI extreme quantile forecasting
The repository contains the codes for predicting the extreme upper quantiles (0.90, 0.95 and 0.97) of Air Quality Index (AQI) using various quantile regression based statistical, machine learning, stand-alone and hybrid deep learning models. 

## List of Models:
1. LASSO quantile regression
2. Ridge quantile regression
3. Elastic Net quantile regression
4. Support vector quantile regression
5. Quantile regression forests
6. Quantile regression XGBoost
7. Quantile regression deep neural network (QRDNN)
8. Quantile regression long short-term memory (QRLSTM) 
9. Quantile regression gated recurrent unit (QRGRU)
10. Quantile regression convolutional neural network (QRCNN)
11. Quantile regression temporal convolutional network (QRTCN)
12. QR-CNN-LSTM
13. QR-LSTM-GRU
